abstract: >-
  We present Continuous Workflow Checker (CWC), a static analysis tool that parses GitHub Actions
  workflows and cross-checks them against application configuration files to detect four types of
  CI/CD anti-patterns. Across 1,984 widely adopted Node.js and Python projects, CWC found
  anti-patterns in 12.4% and 7.0% of repositories, respectively.
